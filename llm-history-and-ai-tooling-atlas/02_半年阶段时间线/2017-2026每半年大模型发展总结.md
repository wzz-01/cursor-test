# 2017-2026 每半年大模型发展总结

## 2017H1-H2：Transformer 奠基

### 代表事件

- Google 提出 Transformer：Attention Is All You Need。

### 领先模型/技术

- Transformer。

### 优势

- 并行训练；
- 长距离依赖建模；
- 为后续 BERT、GPT、T5、LLM 奠定基础。

### 缺点

- 当时还不是“大模型产品”；
- 长序列 attention 成本高；
- 需要大规模数据和算力才能发挥潜力。

### 阶段总结

这是大模型时代的基础架构起点。真正的行业爆发还没来，但方向已经确定：只要数据、算力和规模上去，Transformer 可以承载通用语言能力。

## 2018H1-H2：预训练范式成型

### 代表事件

- OpenAI 发布 GPT-1；
- Google 发布 BERT。

### 领先模型

- BERT：理解任务领先；
- GPT-1：生成式预训练探索。

### 技术主题

- 预训练 + 微调；
- MLM；
- Transformer encoder/decoder 分化。

### 优势

- BERT 显著提升 NLP benchmark；
- 预训练模型可迁移到多任务；
- 学术界和工业界开始进入预训练时代。

### 缺点

- 仍以任务微调为主；
- 生成能力和对话能力不成熟；
- 模型规模还未达到涌现阶段。

## 2019H1-H2：生成模型规模扩大

### 代表事件

- GPT-2 发布；
- T5 发布；
- 大规模预训练模型竞争加速。

### 领先模型

- GPT-2：文本生成；
- T5：text-to-text；
- BERT/RoBERTa：理解任务。

### 优势

- 生成质量明显提升；
- 统一任务格式思想出现；
- scaling 的价值开始显现。

### 缺点

- 幻觉和不可控生成严重；
- 缺少指令遵循；
- 产品化仍有限。

## 2020H1-H2：GPT-3 与 Few-shot 震动行业

### 代表事件

- GPT-3 发布；
- Scaling Laws 受到重视。

### 领先模型

- GPT-3。

### 技术主题

- few-shot prompting；
- in-context learning；
- 大规模 API。

### 优势

- 无需微调即可完成多任务；
- API 商业化雏形；
- prompt 成为新交互方式。

### 缺点

- 指令遵循不稳定；
- 事实幻觉明显；
- 成本高；
- 不适合可靠执行任务。

## 2021H1-H2：代码模型与对话模型前夜

### 代表事件

- OpenAI Codex；
- GitHub Copilot 技术基础；
- Google LaMDA；
- DeepMind Gopher。

### 领先模型

- Codex：代码；
- LaMDA：对话；
- Gopher：大规模语言模型。

### 技术主题

- 代码生成；
- 对话建模；
- 更大规模训练。

### 优势

- 代码能力开始成为大模型核心能力；
- Copilot 证明开发者付费场景；
- 对话体验进步。

### 缺点

- 可靠性不足；
- 仍缺少 RLHF 大规模产品验证；
- 代码生成需要人工审查。

## 2022H1：对齐方法成熟

### 代表事件

- InstructGPT；
- RLHF 流程被验证；
- Chinchilla 讨论 compute-optimal。

### 领先模型

- InstructGPT；
- Chinchilla/Gopher 路线；
- PaLM。

### 技术主题

- SFT；
- Reward Model；
- RLHF；
- 数据与参数平衡。

### 优势

- 模型更会遵循人类指令；
- 对齐成为产品化关键；
- 训练策略从“只堆参数”转向数据/计算平衡。

### 缺点

- RLHF 成本高；
- reward hacking 风险；
- 对齐不等于事实正确。

## 2022H2：ChatGPT 引爆

### 代表事件

- ChatGPT 发布。

### 领先模型

- ChatGPT / GPT-3.5。

### 技术主题

- 对话式 AI；
- RLHF 产品化；
- 通用 AI 助手。

### 优势

- 用户体验巨大跃迁；
- 大模型首次成为全球级消费产品；
- 开启 AI 应用创业浪潮。

### 缺点

- 幻觉；
- 数学和复杂推理不足；
- 无法可靠使用工具；
- 知识有时效限制。

## 2023H1：GPT-4 与开源生态爆发

### 代表事件

- GPT-4 发布；
- Claude 发布；
- LLaMA 泄露/开放研究权重后引爆社区；
- ChatGPT Plugins。

### 领先模型

- GPT-4：综合领先；
- Claude：安全和长文本；
- LLaMA：开源生态。

### 技术主题

- 多模态；
- 插件；
- 开源微调；
- RLHF 竞争。

### 优势

- GPT-4 推理和代码能力显著领先；
- 开源社区开始快速追赶；
- 插件开启工具调用想象。

### 缺点

- 插件生态体验不稳定；
- 开源模型仍明显落后 GPT-4；
- 企业落地缺少评估和安全框架。

## 2023H2：RAG、Agent、开源模型快速发展

### 代表事件

- Llama 2；
- Claude 2；
- GPT-4 Turbo；
- Mistral 7B / Mixtral；
- Qwen、ChatGLM、Baichuan 等国内模型发展；
- AutoGPT、LangChain、LlamaIndex 热度上升；
- ReAct、Reflexion、AutoGen、MetaGPT 等 Agent 论文/框架活跃。

### 领先模型

- GPT-4 Turbo；
- Claude 2；
- Llama 2；
- Mistral/Mixtral；
- Qwen。

### 技术主题

- RAG 企业落地；
- Agent 原型；
- 开源模型；
- 函数调用；
- 长上下文。

### 优势

- 企业知识库成为第一批落地场景；
- 开源模型可私有化；
- Agent 框架生态形成。

### 缺点

- Agent demo 多，稳定产品少；
- 工具调用不可靠；
- RAG 评估薄弱；
- 多 Agent 容易成本爆炸。

## 2024H1：多模态与长上下文竞争

### 代表事件

- Claude 3；
- Gemini 1.5；
- GPT-4o；
- Llama 3；
- Qwen2；
- DeepSeek-Coder；
- Kimi 长上下文产品走红。

### 领先模型

- GPT-4o：实时多模态；
- Claude 3 Opus/Sonnet：文档和代码；
- Gemini 1.5 Pro：长上下文；
- Llama 3：开源；
- Qwen2/DeepSeek：中文和代码。

### 技术主题

- 多模态原生；
- 长上下文；
- 低延迟语音/视觉；
- 开源追赶；
- RAG 工程化。

### 优势

- 模型从文本走向图像、音频、视频；
- 长文档处理成为常见能力；
- AI 编程工具开始进入主流开发流程。

### 缺点

- 长上下文成本和注意力噪声；
- 多模态事实性不足；
- 工具和 Agent 仍不稳定。

## 2024H2：推理模型路线出现

### 代表事件

- OpenAI o1 类推理模型；
- Claude 3.5 Sonnet 在 coding 中广泛使用；
- Cursor/Windsurf 等 AI IDE 爆发；
- SWE-bench 成为代码 Agent 关键指标。

### 领先模型

- o1：复杂推理；
- Claude 3.5 Sonnet：代码和日常 Agent；
- GPT-4o：多模态和综合；
- Gemini 1.5：长上下文；
- Qwen2.5/DeepSeek-Coder：开源代码。

### 技术主题

- test-time scaling；
- 长 CoT；
- AI IDE；
- SWE-bench；
- Agentic coding。

### 优势

- 模型开始愿意“慢思考”；
- 软件工程成为最重要落地场景；
- AI IDE 从补全走向多文件编辑。

### 缺点

- 推理模型成本高；
- 长思考不一定正确；
- AI 编程工具容易误改；
- 评估与真实生产仍有差距。

## 2025H1：DeepSeek-R1 与 Agent 工具爆发

### 代表事件

- DeepSeek-R1 引发开源推理模型热潮；
- Claude Code、Codex CLI、Gemini CLI、Devin 等 Agent 工具成熟；
- Llama 4 / Qwen3 / Gemini 2.x / Claude 3.7 等路线发展；
- MCP 成为工具协议关注点。

### 领先模型

- DeepSeek-R1：开放推理和性价比；
- Claude 3.7/4 前夜：代码；
- OpenAI o 系列：推理和工具；
- Gemini 2.x：多模态和长上下文；
- Qwen3：中文、开源、推理。

### 技术主题

- 推理强化；
- Agent coding；
- MCP；
- 开源模型成本革命；
- AI 编程工具组合工作流。

### 优势

- 开源模型明显缩小差距；
- 推理能力成为模型竞争核心；
- CLI Agent 能独立完成更复杂任务。

### 缺点

- 成本和延迟仍高；
- 工具权限安全问题突出；
- 自主代码修改仍需人工 review。

## 2025H2：Agent 从玩具走向生产

### 代表事件

- 企业开始部署内部 Agent；
- AI IDE 支持后台 Agent、并行任务；
- GitHub Copilot Coding Agent、Cursor Background Agents、Codex Cloud Agents 等形态出现；
- Agent 评估、安全、观测平台重要性上升。

### 领先模型

- Claude Sonnet/Opus 系列：代码和 Agent；
- GPT-5/o 系列：综合和工具生态；
- Gemini 2.5/3 前夜：多模态和性价比；
- DeepSeek/Qwen/Kimi：开源与中文生态。

### 技术主题

- 后台 Agent；
- 多 Agent 并行；
- 企业权限；
- trace；
- Agent evaluation。

### 优势

- Agent 不再只是聊天窗口，而是进入 issue、PR、CI、文档和研发流程；
- 成本下降；
- 工具生态丰富。

### 缺点

- 多 Agent 难治理；
- hallucination 变成“错误执行”；
- 企业合规和审计压力上升。

### 代表事件

- Claude 4.x；
- Gemini 3.x；

- Qwen3.x；

- Cursor、Windsurf、Claude Code、Codex CLI、Gemini CLI、Copilot Coding Agent 等工具进一步成熟。

### 领先模型格局

- 模型榜单不再足够区分真实能力；

- 安全风险从“说错话”变成“做错事”。

# 总体规律

1. 每一轮领先模型的领先周期在缩短。
2. Benchmark 很快饱和，真实任务评估更重要。
3. 开源模型持续压低成本，闭源模型保持前沿能力优势。
4. 模型能力越强，系统安全越重要。
5. Agent 时代的竞争核心是“模型 + 工具 + 状态 + 权限 + 评估”的整体系统。
