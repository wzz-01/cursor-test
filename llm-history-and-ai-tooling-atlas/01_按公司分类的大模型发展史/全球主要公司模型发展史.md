# 全球主要公司大模型发展史

> 说明：模型更新极快，本文件按公开资料整理，重点是发展脉络、产品定位、优势短板和选型判断。

# 一、国外主要公司

## 1. OpenAI

### 发展路线

| 阶段 | 代表模型/产品 | 关键意义 |
| --- | --- | --- |
| 2018 | GPT-1 | 验证 Transformer decoder 预训练可迁移 |
| 2019 | GPT-2 | 大规模生成模型引发文本生成关注 |
| 2020 | GPT-3 | few-shot / in-context learning 进入公众视野 |
| 2021 | Codex | 代码生成和 GitHub Copilot 基础 |
| 2022 | InstructGPT / ChatGPT | RLHF + 对话产品引爆行业 |
| 2023 | GPT-4 / GPT-4V | 强推理、多模态、代码能力领先 |
| 2024 | GPT-4o / o1 | 实时多模态与推理模型路线 |
| 2025 | GPT-4.1 / o3 / Codex Agent 路线 | 长上下文、代码和 Agent 能力增强 |
| 2026 | GPT-5.x / GPT-5.5 类前沿模型 | 更强 agentic coding、computer use、长上下文和工作流自动化 |

### 主要模型家族

- GPT 系列：通用文本、推理、对话；
- GPT-4o 系列：多模态实时交互；
- o 系列：推理模型，面向复杂数学、代码和规划；
- Codex 系列：代码生成、软件工程、Agent coding；
- Embedding / TTS / Vision / Realtime 系列：构成多模态平台。

### 优势

1. 综合能力强，模型、产品、API、工具链完整；
2. ChatGPT 拥有最强 C 端心智；
3. Codex、函数调用、Agents SDK、Computer Use 等生态领先；
4. 模型迭代和产品化速度快；
5. 第三方生态丰富，集成成本低。

### 缺点

1. 闭源，企业难以完全掌控；
2. 成本和调用限制需要关注；
3. 部分模型行为和系统策略不可完全解释；
4. 数据合规、跨境和私有化部署存在约束。

### 适合场景

- 通用 AI 应用；
- Agent 平台；
- 代码助手；
- 高质量内容生成；
- 多模态交互；
- 企业快速原型。

## 2. Anthropic

### 发展路线

| 阶段 | 代表模型/产品 | 关键意义 |
| --- | --- | --- |
| 2022 | Claude 早期模型 | 强调 helpful、harmless、honest |
| 2023 | Claude 1/2 | 长上下文、安全对齐、企业使用 |
| 2024 | Claude 3 / 3.5 Sonnet | 编码、写作、长文档、视觉能力显著提升 |
| 2025 | Claude 3.7 / Claude Code | coding agent 和复杂推理成为优势 |
| 2026 | Claude 4.x / Opus/Sonnet 路线 | 长任务软件工程、企业安全和 agentic coding 领先 |

### 主要模型家族

- Claude Haiku：低成本高速；
- Claude Sonnet：性价比和 coding；
- Claude Opus：最强能力；
- Claude Code：终端代码 Agent；
- Claude Desktop + MCP：工具生态入口。

### 优势

1. 代码理解、复杂重构、长任务表现强；
2. 长上下文和文档处理体验好；
3. 安全、对齐、企业信任度高；
4. Claude Code 在 CLI Agent 中影响力大；
5. MCP 推动工具协议生态。

### 缺点

1. 闭源；
2. 多模态和生态广度相对 OpenAI/Google 弱；
3. 成本通常偏高；
4. 强模型延迟和费用需要控制。

### 适合场景

- 复杂代码任务；
- 架构设计和代码审查；
- 企业知识处理；
- 长文档分析；
- 高安全要求的企业 Agent。

## 3. Google / DeepMind

### 发展路线

| 阶段 | 代表模型/产品 | 关键意义 |
| --- | --- | --- |
| 2017 | Transformer | 大模型时代基础架构 |
| 2018 | BERT | 预训练语言理解模型爆发 |
| 2019 | T5 | text-to-text 统一范式 |
| 2021 | LaMDA / PaLM | 对话和大规模语言模型 |
| 2023 | Bard / Gemini 1.0 | Google 进入 ChatGPT 竞争 |
| 2024 | Gemini 1.5 | 长上下文、多模态、Workspace 生态 |
| 2025 | Gemini 2.x / Deep Think | 推理、多模态、开发者工具 |
| 2026 | Gemini 3.x / Flash/Pro 路线 | 高性价比、多模态、长上下文和 Agent 工作流 |

### 主要模型家族

- BERT/T5：基础 NLP；
- PaLM/LaMDA：早期大模型；
- Gemini Pro/Flash/Nano：多档位模型；
- Gemma：开放权重小模型；
- Imagen/Veo/MusicLM 等：生成式多模态；
- Jules/Gemini CLI：开发者 Agent。

### 优势

1. 技术基础深厚，Transformer/BERT/T5 均来自 Google；
2. 搜索、YouTube、Android、Workspace 生态强；
3. 多模态和长上下文能力强；
4. Flash 系列性价比和速度突出；
5. TPU 和云基础设施完整。

### 缺点

1. 产品命名和迭代路线曾较混乱；
2. 开发者心智一度落后 OpenAI；
3. 企业集成需依赖 Google Cloud 生态；
4. 部分模型地区可用性和产品节奏不一致。

### 适合场景

- 长文档处理；
- 多模态理解；
- Google Workspace 自动化；
- 高吞吐低成本任务；
- 搜索增强和研究任务。

## 13. Perplexity

### 定位

Perplexity 更像 AI 搜索产品公司，而不是单纯基础模型公司。它将搜索、引用、答案生成和模型路由结合，代表“答案引擎”方向。

### 优势

- 搜索体验好；
- 引用清晰；
- 适合研究和资料查询；
- 多模型路由。

### 缺点

- 基座模型依赖外部和自研混合；
- 不适合作为所有企业 Agent 底座。

# 四、总体结论

1. **闭源前沿模型**：OpenAI、Anthropic、Google 仍是综合前沿主力。
2. **开放权重模型**：Meta、Qwen、DeepSeek、Mistral 是主要力量。
3. **中文模型**：Qwen、DeepSeek、百度、腾讯、字节、智谱、Kimi 各有侧重。
4. **企业应用**：不应只看模型榜单，要看云生态、权限、安全、成本、工具链。
5. **Agent 时代**：模型本身只是底座，真正竞争在工具调用、记忆、评估、IDE/CLI/云 Agent 生态。
