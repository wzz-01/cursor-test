## 0. 你要完成什么

为指定省区生成《销售管理日简报》中的核心三段文字：

1. **区域销售进度**（当月）
2. **业绩预警 / 市场问题**（近3个快照月）
3. **年度目标**（本财年至今）

原则：

- 数字必须来自 SQL，可追溯
- 禁止编造
- 落款日期 ≠ 取数快照日（见下文）
- **每次**有人询问「某省区销售管理日简报 / ①②③结论」时：
  - **必须按昨天（D_biz=昨天）重新计算**，禁止复用历史对话里的旧结论、旧日期、旧数字
  - 默认只回复三段结论正文
  - 省区名以用户本次输入为准；不存在则列候选，禁止擅自改名后出数

## 2. 日期规则（最容易错，必须先懂）

### 2.1 业务日 vs 取数日

本表 `date_id` **不是自然日流水**，业务日期被归到**当月 1 号快照**。

**默认规则（每天自动，不要等用户改日期）：**

- `D_biz` = **昨天**（按运行当日自然日减 1 天；可用 `CURRENT_DATE - INTERVAL 1 DAY`）
- 用户未特别指定日期时，**禁止写死某个历史日期**，每次执行都重新取昨天
- 仅当用户明确指定某日时，才覆盖默认的昨天

| 概念 | 含义 | 如何计算 |
|------|------|----------|
| 业务日 `D_biz` | 报告落款「截至日」 | **默认 = 昨天** |
| 取数快照日 `D0` | `D_biz` 所在月的 1 号 | `DATE_FORMAT(D_biz, '%Y-%m-01')` |
| 同比快照日 `D0_ly` | 去年同月 1 号 | `D0` 减一年 |

**正文写「截至{月}月{日}日」（用 D_biz），取数用 D0。禁止把落款写成月初 1 号。**

示例（仅帮助理解，不是固定参数）：若今天是 7月21日，则 `D_biz=7月20日`，`D0=7月1日`，`D0_ly=去年7月1日`。

### 2.2 财年

- 财年 = **当年 7/1 ~ 次年 6/30**
- 例：2025-07-01 ~ 2026-06-30 = **2025 财年**
- 例：2026-07-01 ~ 2027-06-30 = **2026 财年**
- 所有“年累计 / 年度目标”按财年，**禁止按自然年 1–12 月**
- 本期/去年财年缩写用 `fiscal_year_abbreviation`（如 F26/F25），随 `D_biz` 所属财年自动判断

### 2.3 三段时间窗（必须分开，禁止混用）

每次先由 `D_biz=昨天` 推导窗口（下面用“若昨天落在某年7月”举例）：

| 段落 | 时间窗 | 取数日期 |
|------|--------|----------|
| ① 区域销售进度 | 仅业务日所在月 | `D0` vs `D0_ly` |
| ② 业绩预警 | 近 3 个快照月 | `D0` 及往前两个月的 1 号 |
| ③ 年度目标 | 本财年起始 ~ 当前月快照 | 本期：本财年7/1 ~ `D0`；去年同期：上财年对应区间 |

说明：当 `D_biz` 落在财年首月时，③ 的年累计会接近当月快照，**这是正确现象**。

## 3. 计算公式

### 通用

- 金额展示：**原值 / 10000 → 万元**
- 达成率 = `SUM(amt_yesterday) / SUM(ys_products)`
- **预算不去重**（直接 SUM，不要 MAX/row grain 折预算）
- 同比增额 = 本期 - 去年同期
- 同比增速/增长率 = 增额 / 去年同期（除零 → 见下方「新渠道/同期为0」规则）

### 新渠道 / 去年同期为 0 的增速规则（通用，已锁定）

适用于①增长率、③同比增速，以及所有依赖该增速的排名：

- 当**去年同期对照值 = 0**（或缺失导致无法做常规除法），且**本期值 > 0** 时：
  - **增速/增长率按 100% 计**
  - **同比增额仍按「本期 - 去年同期」计算**（同期为 0 时增额=本期）
  - **增速排名必须用上述 100% 结果参与排序**，不要因除零写成「待补」或排除出排名
- 当去年同期为 0 且本期也为 0：增速按 0%（或并列处理），不要写待补
- 典型场景：专客等新渠道（如 `华南专客`）历史同期无销售
- 此规则对所有省区/渠道一视同仁，不只限华南专客

### ① 区域销售进度（当月）

在省区 + `D0` 上计算：

- 销售额、同比增额、达成率、增长率
- 省区达成率排名、增长率排名（在全部 `province_region_name` 中）
- 经销达成/增长、直营达成/增长
- 预估本月达成：优先评估 `amt_yg`；不合理则标「待补」
- 大单品达成率：按已锁定物料组编码清单，在当月 `D0` 上
  - 实际 = `SUM(amt_yesterday)`（编码命中）
  - 预算 = `SUM(ys_products)`（编码命中，不去重）
  - 达成率 = 实际 / 预算
  - **能算出时**：正文写 `（其中大单品达成率：XX%）`
  - **算不出时**（预算为0、无命中、无销售等）：**整段括号省略，不要写**「（其中大单品达成率：…）」或「算不出」
- Top / Bottom 销售组展示（按该省区当月销售组数量 `N`，已锁定）：
  - **若 N ≥ 6**：保持原样句  
    `达成率前三分区/销售组依次为：A(xx%)、B(xx%)、C(xx%)，后三为：D(xx%)、E(xx%)、F(xx%)。`
  - **若 N < 6**：不写前三/后三，改为：
    - **N ≤ 3**：全部罗列  
      `销售组达成率：A(xx%)、B(xx%)、C(xx%)。`
    - **3 < N < 6**（即 4 或 5 个）：只写最好 1 个 + 最差 1 个  
      `达成率最高销售组为：A(xx%)，最低为：B(xx%)。`
  - 若 N=1：只罗列该组一次，不要前三后又三重复
  - 不要输出「（单位名称加达成）」

### ② 业绩预警（近3月）

- 快照日：`date_id IN (D0, add_months(D0,-1), add_months(D0,-2))`  
  例：业务日在 2026-07 时，固定为 `2026-07-01 / 2026-06-01 / 2026-05-01`
- **月销额字段规则（已纠偏，重要）**：
  - **当月快照 D0**：用 `SUM(amt_yesterday)`
  - **上月、上上月快照**：用 `SUM(amt_last_month)`（完整月销额）
  - 原因：财年从 7/1 起，底表 `amt_yesterday` 通常只有本财年 7 月至今数据；若近 3 月跨到财年前的 5/6 月，`amt_yesterday` 会为 0，导致误判「无下滑」
  - 禁止近 3 个月全部只用 `amt_yesterday`
- 连续三月下滑：城市 / 销售组 / 客户，按上述字段取出三个月销额后，严格 `M1 > M2 > M3` 才命中
- 近三月达成率全国后 20% 销售组：
  - 近 3 月销额侧同样按「当月 amt_yesterday + 上两月 amt_last_month」汇总
  - 预算侧仍用对应快照月 `SUM(ys_products)`（不去重）
  - 全国销售组排序后取后 20%，再筛本省区
- 四项全无命中时输出：
  `省区内无连续三个月下滑城市，无连续三个月下滑销售组，无连续三个月下滑客户，其中无销售组近三月达成率处于全国后20%，`

### ③ 年度目标（财年至今）

- 年累计销额（分子）= 本财年起始日 ~ `D0` 的 `SUM(amt_yesterday)`
- 去年同期年累计 = 上财年对应区间 `SUM(amt_yesterday)`
- 增额 / 同比增速：基于上述两个年累计（方案1）
- **累计进度分母 = 该省区本财年「全年预算」**，不是“财年至今/当月快照预算”
  - 全年预算取 `ys_products`，`SUM` 不去重
  - **已确认取法**：用字段 `fiscal_year_abbreviation` 圈定财年，再 `SUM(ys_products)`
    - 本期示例：`fiscal_year_abbreviation = 'F26'`（对应 2026 财年）
    - 去年示例：`fiscal_year_abbreviation = 'F25'`（对应 2025 财年）
  - 这是月度快照表，需把该财年下全部快照月预算相加（通常 12 个 `month_cn_name`），**不能**只用 `D0` 当月预算
  - 若后续月份预算已写入，必须纳入全年预算分母
- 累计进度 = 年累计销额 / 全年预算
- **同期实际进度**（已纠偏）：
  - 公式：去年同期年累计销额 ÷ 去年同期所有月份完整月销额
  - 分子：上财年对应区间 `SUM(amt_yesterday)`（与「去年同期年累计」相同）
  - 分母：上财年完整年度 `SUM(amt_last_month)`（完整月销额；按 `fiscal_year_abbreviation` 如 F25 全量）
  - **分母不是 `ys_products`，也不是只用去年截止当月**
  - 验证锚点：1638.68 ÷ 53114.59 ≈ **3.1%**（保留1位小数）；禁止再写 8.1% / 10.12%
- 在全部省区单位中：进度排名、增速排名（进度分母仍用各省区全年预算 `ys_products`）

### ③纠偏｜累计进度分母与同期实际进度（必读）

**累计进度错误示例（禁止再犯）：**

> 累计进度53.4% …（用当月/财年至今预算当分子分母，实为当月达成）

**同期实际进度错误示例（禁止再犯）：**

> 同期实际进度：8.1% / 10.12% / **10.8%** …（误用去年全年预算 `ys_products` 作分母）

正确分母是**去年全年销额**（上财年全年 `SUM(amt_last_month)`），不是预算。

**正确对照：**

| 项 | 正确做法 | 错误做法 |
|----|----------|----------|
| 累计进度分子 | 本财年起始 ~ `D0` 的 `SUM(amt_yesterday)` | — |
| 累计进度分母 | Fxx 全年 `SUM(ys_products)` | 当月/至今预算 |
| 同期实际进度分子 | 去年同期年累计 `SUM(amt_yesterday)` | — |
| 同期实际进度分母 | 上财年全年 `SUM(amt_last_month)` | 上财年全年 `ys_products` |
| 同期实际进度锚点 | 用 `amt_last_month` 作分母（曾核约 **3.1%**） | 用预算作分母得到 8.1% / 10.12% / **10.8%**（全错） |

**与第一段的区别：**

- ① 达成率分母 = 当月预算 `ys_products`
- ③ 累计进度分母 = 全年预算 `ys_products`
- ③ 同期实际进度分母 = 上财年全年完整月销额 `amt_last_month`

## 4. 必须严格套用的输出句式

### 第一段（截图1）

> 截至X月X日，XX省区实现销售额XX万元，同比增加XX万元，达成率XX（其中大单品达成率：XX），增长率XX，达成率排名第X位，增长率排名第X位；经销达成XX，增长XX，直营达成XX，增长XX，结合当前进度及同期实际值，预估本月达成约XX。{销售组达成结尾}

注意：
- `截至X月X日` 用 **业务日 D_biz**，不是 D0
- 大单品能算才写括号；**算不出则整段「（其中大单品达成率：…）」删除，不要写算不出**
- 不要输出「（单位名称加达成）」说明文字
- **销售组达成结尾**按数量 `N`：
  - **N ≥ 6**：`达成率前三分区/销售组依次为：…，后三为：…。`
  - **N ≤ 3**：`销售组达成率：A(xx%)、B(xx%)…。`
  - **3 < N < 6**：`达成率最高销售组为：A(xx%)，最低为：B(xx%)。`
  - 不要输出「（单位名称加达成）」

### 第二段（截图2）

有命中时：

> 省区内连续三个月下滑城市有……，销售组有……，客户有……，其中X、X销售组近三月达成率处于全国后20%，

无命中时（推荐）：

> 省区内无连续三个月下滑城市，无连续三个月下滑销售组，无连续三个月下滑客户，其中无销售组近三月达成率处于全国后20%，

不要写「城市有无，销售组有无」。

### 第三段（截图3）

> 年度目标：年累计销额XX万，增额XX万，累计进度XX（同期实际进度：XX），同比增速XX；在XX省区单位中，进度排名第X位，增速排名第X位。

同期实际进度按「去年同期年累计 ÷ 上财年全年 amt_last_month」填写，保留1位小数。

## 7. 禁止事项

- 不要把落款写成快照日 1 号
- **不要把业务日写死成某个历史日期**；默认每天取昨天，除非用户明确指定某日
- 不要用自然年做年累计
- 不要用 `amt_last_month` 做同比增额/增速；但③同期实际进度分母必须用上财年全年 `amt_last_month`
- 不要对年度/当月预算做 MAX 去重（本任务明确不去重）
- **不要把「当月/财年至今预算」当成年度累计进度的分母**（见「③纠偏」；错误：1642/3075≈53.4%；正确：1642/59302≈2.8%）

- 不要把①的达成率与③的累计进度混为同一个分母口径
- 不要把①②③时间窗混在一段里
- 不要编造大单品、拜访、费用、订单数
- 查不到就写「算不出 + 原因」
- **日常回复不要输出日期回显表、关键结果表、长分析**；默认只给三段结论
- **例外**：去年同期为 0、本期 > 0 时，增速/增长率不要写待补，按 **100%** 计，并据此参与增速排名（见「新渠道/同期为0」规则）
