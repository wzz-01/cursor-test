# 省区销售管理日简报 · 智能体训练说明

每次有人询问「某省区销售管理日简报」时：按**昨天**重新取数，只回复结论正文。

- **已锁定可出：** ①②③④  
- **新模块（表名锁定后出）：** ⑤费用、⑥拜访  
- ⑤⑥ 数据源未锁定或查不到时：费用写「本版暂无费用数据」；拜访写「本版暂无拜访数据」，**禁止编造**  
- 探表话术见同目录 `06_hermes_探表_费用拜访.md`

---

## 1. 执行顺序

1. 确认省区全称；名称不唯一时先列候选请用户选择  
2. 业务日 `D_biz` = 昨天；推算 `D0`、近3月快照、财年缩写  
3. 计算①当月进度 → ②近3月预警 → ③年度目标 → ④昨日订单 → ⑤费用 → ⑥拜访  
4. 只输出样句正文（用户要核对表/SQL 时再补过程）

---

## 2. 数据源

### 表 A（①②③）— 已锁定

- 表：`market_db.dwd_sales_fiveyears`
- 主金额：`amt_yesterday`
- 完整月销额：`amt_last_month`
- 预算：`ys_products`（直接 `SUM(ys_products)`）
- 财年字段：`fiscal_year_abbreviation`（如 `F26` / `F25`）
- 渠道：`cust_group_classify`（正文「经销」←`经销商`，「直营」←`直营`）
- 日期字段：`date_id`

### 表 B（④）— 已锁定

- 表：`market_db.dwd_sales_daily_detail`（以实际库名为准）
- 日期字段：`riqi`（业务日，等于昨天）
- 下单额：`amt`
- 下单量：`qty`
- 月预算：`ys_p`
- 省区、销售组、客户等维度字段按表内实际名称（如省区名、销售组、客户编码/名称）

### 表 C（⑤费用）— 待探表锁定

- 候选库：`market_db`、费用相关 ODS（探表后回填 `库.表`）
- 需具备：省区、业务日/月份、费用发生额、费用预算（或可关联预算表）
- **未锁定前：** 不猜表；正文「费用使用情况：本版暂无费用数据」

### 表 D（⑥拜访）— 待探表锁定

- 候选库优先：`ods_sfa`，其次 `market_db` / `dw` / `ods_master`
- 需具备：省区、业务日、人员、客户/门店/经销拜访动作
- **未锁定前：** 不猜表；正文「昨日拜访情况：本版暂无拜访数据」

金额展示：原值 ÷ 10000 → **万元**（费用同此；拜访家数/人数不换算）。  
日期对齐为 `YYYY-MM-DD`，避免时区转换导致偏移。  
①～⑥ 取数统一走 **Doris 直连 `market`**，不要用内部销售 MCP 查无权限的表。

## 3. 日期

| 概念 | 算法 | 用途 |
|------|------|------|
| `D_biz` | 昨天 | 正文落款「截至X月X日」 |
| `D0` | `D_biz` 所在月 1 号 | 当月取数快照 |
| `D0_ly` | `D0` 减一年 | 当月同比 |
| 近3月 | `D0`、`D0`往前1个月初、`D0`往前2个月初 | ②预警 |
| 本财年 | 当年 7/1～次年 6/30；用 `fiscal_year_abbreviation` | ③年累计 |

正文落款只用 `D_biz`；`D0` 仅用于过滤 `date_id`。

## 4. ① 区域销售进度（当月）

**范围：** `province_region_name = 指定省区` 且 `date_id = D0`

| 指标 | 算法 |
|------|------|
| 销售额 | `SUM(amt_yesterday)` |
| 同比增额 | 本期销售额 − `D0_ly` 同口径销售额 |
| 增长率 | 同比增额 ÷ 去年同月销售额 |
| 达成率 | `SUM(amt_yesterday) ÷ SUM(ys_products)`（当月） |
| 达成率/增长率排名 | 全部 `province_region_name` 按该指标排序 |
| 经销/直营达成与增长 | 按 `cust_group_classify` 分组，同上 |
| 预估本月达成 | 可用 `amt_yg` 合理估算时填写 |

**去年同期为 0、本期 > 0：** 增长率按 **100%**，并参与增长率排名。

- **4 ≤ N ≤ 5：** `达成率最高销售组为：A(xx%)，最低为：B(xx%)。`

## 5. ② 业绩预警（近3月）

**快照日：** `D0`、上月初、上上月初（例：`2026-07-01 / 2026-06-01 / 2026-05-01`）

### 每月销额用哪一列

| 月份 | 本期销额 | 去年同月销额 |
|------|----------|--------------|
| 当月 `D0` | `SUM(amt_yesterday)` | 去年同月 `SUM(amt_yesterday)` |
| 上月、上上月 | `SUM(amt_last_month)` | 去年同月 `SUM(amt_last_month)` |

此规则**每个月都适用**（含非财年初）。

### 连续三个月下滑

对象：城市 / 销售组 / 客户  

对近 3 个快照月分别算：  
`同比增额 = 本期该月销额 − 去年同月销额`  

**命中：** 三个月同比增额**都 < 0**。  

用同比增额判断，不用本期三个月销额的环比升降。

### 近三月达成率全国后 20%

- 销售组近 3 月销额 = 当月 `amt_yesterday` + 其余两月 `amt_last_month`  
- 近 3 月预算 = 三个快照月 `SUM(ys_products)`  
- 达成率 = 近 3 月销额 ÷ 近 3 月预算  
- 全国所有销售组排序后取后 20%，再筛本省区  

### ② 正文

有命中：写出名称。  

全无命中：

> 省区内无连续三个月下滑城市，无连续三个月下滑销售组，无连续三个月下滑客户，其中无销售组近三月达成率处于全国后20%，

## 6. ③ 年度目标（财年）

| 指标 | 算法 |
|------|------|
| 年累计销额 | 本财年起始日～`D0`，`SUM(amt_yesterday)` |
| 去年同期年累计 | 上财年对应区间，`SUM(amt_yesterday)` |
| 增额 / 同比增速 | 本期年累计相对去年同期年累计（主金额均为 `amt_yesterday`） |
| 全年预算 | 本财年 `fiscal_year_abbreviation` 下 `SUM(ys_products)`（完整财年，如 F26 全部月份） |
| **累计进度** | 年累计销额 ÷ **全年预算** |
| **同期实际进度** | 去年同期年累计 ÷ 上财年全年 `SUM(amt_last_month)`（分母是**全年销额**，用 `amt_last_month`） |
| 进度/增速排名 | 见下 |

**累计进度**看的是全年预算进度；**①达成率**看的是当月预算。二者分子分母都不同，排名可以不同。

**去年同期为 0、本期 > 0：** 同比增速按 **100%**，并参与增速排名。

### 排名样本

- 样本 = 当期全部 `distinct province_region_name`  
- 正文「在 X 个省区单位中」的 X 用该全量个数  
- 名称关键词、电商等均计入样本  

### ③ 正文模板

> 年度目标：年累计销额XX万，增额XX万，累计进度XX（同期实际进度：XX），同比增速XX；在XX省区单位中，进度排名第X位，增速排名第X位。

## 7. ④ 昨日订单情况（表 B）

**表：** `dwd_sales_daily_detail`  
**省区范围：** 与用户指定省区一致  
**昨日：** `riqi = D_biz`（昨天）

### 首句指标

| 文案 | 算法 |
|------|------|
| 下单额（万元） | `riqi=昨天` 时 `SUM(amt)`，再 ÷10000 |
| 下单量（件） | `riqi=昨天` 时 `SUM(qty)` |
| 占全月预算 | `SUM(amt) ÷ SUM(ys_p)`（同一昨日范围；`ys_p` 为月预算） |
| 订单数（单） | 按表内订单号字段去重计数；若无订单号字段，先确认字段后再计 |

### 连续5日未下单销售分区/销售组

- 看近 5 个自然日（含昨天往前共 5 天）是否有下单（`amt>0`）  
- 输出：这 5 天都没有下单记录的销售分区/销售组名称  

### 当月未下单客户

- 参照：本月应跟踪的客户集合（与业务约定一致；若用 `yuefen` 等月度活跃口径，按用户当次说明）  
- 输出：当月截至昨天仍无下单（无 `amt>0`）的客户  

### 附：下单客户清单及下单量

- 范围：`riqi=昨天` 且 `amt>0`（或有下单）的客户  
- 字段：客户编码、客户名称、下单额、下单量（及销售组，若需要）

### ④ 正文模板

> 昨日共计下单XX万元，XX件，占全月预算的XX，订单数XX单，连续5日未下单销售分区/销售组有……，当月未下单客户有：……  
> 附：下单客户清单及下单量  
> （清单可表格式附在④后）

## 8. ⑤ 费用使用情况（表 C，待锁定）

**范围：** 指定省区；业务日 `D_biz`=昨天  

| 指标 | 默认算法（探表确认后可改） |
|------|---------------------------|
| 费用使用额 | 当月截至昨天 `SUM(费用发生额)` ÷10000 → 万元 |
| 费用预算 | 当月 `SUM(费用预算)` ÷10000 → 万元 |
| 费用使用率 | 使用额 ÷ 预算 |

- 预算为 0、无表、无权限：整段写「费用使用情况：本版暂无费用数据」  
- 样例原文常仅有模块标题；有数时按下述模板展开  

### ⑤ 正文模板

> 费用使用情况：截至X月X日，费用使用额XX万元，预算XX万元，使用率XX。

或：

> 费用使用情况：本版暂无费用数据

## 9. ⑥ 昨日拜访情况（表 D，待锁定）

**范围：** 指定省区；昨日 = `D_biz`  

| 指标 | 默认算法（探表确认后可改） |
|------|---------------------------|
| 昨日拜访客户数 | `D_biz` 去重客户数（家） |
| 客户月累计覆盖率 | 本月截至昨天去重拜访客户 ÷ 应拜访客户分母 |
| 昨日拜访门店数 | `D_biz` 去重门店数（家） |
| 门店月累计覆盖率 | 本月截至昨天去重拜访门店 ÷ 应拜访门店分母 |
| 参与拜访人数 | `D_biz` 去重人员数（人） |
| 负责人拜访 | 有负责人标识时，按分区/销售组汇总负责人昨日拜访经销数、门店数；无标识则省略 |

- **有效拜访（默认）：** 有拜访记录即算；不要擅自加停留时长过滤  
- **覆盖率分母：** 必须以探表确认的「应拜访」清单为准；算不出则写「暂无法计算」，不编造  
- **无表/无权限：** 「昨日拜访情况：本版暂无拜访数据」  

### ⑥ 正文模板

> 昨日拜访客户XX家，月累计覆盖率XX，拜访门店XX家，月累计覆盖率XX，有XX人参与拜访，{负责人半句或省略}。  
> 附：拜访个人明细  
> 姓名 | 拜访经销数 | 拜访门店数  
> ……
