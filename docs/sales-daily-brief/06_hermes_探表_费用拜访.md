## B. 表名确认后 · 锁定口径再发给 Hermes

把【】里替换成探表结果后发送：

```text
【锁定新数据源】
- ⑤费用表：【库.表】；日期字段【】；金额【】；预算【】；省区【】
- ⑥拜访表：【库.表】；日期字段【】；人员【】；客户【】；门店【】；经销【】；省区【】；是否负责人【有则写字段，无则写无】

【口径（先按此执行，有冲突再报）】
⑤费用：
- 业务日 D_biz=昨天
- 使用额 = 当月截至昨天 SUM(费用发生额) ÷10000 → 万元（若表是日流水）
- 预算 = 当月费用预算 SUM ÷10000
- 使用率 = 使用额 ÷ 预算；预算为 0 则写「本版暂无费用数据」
- 无费用表或无权限：正文只保留「费用使用情况：本版暂无费用数据」

⑥拜访：
- 昨日拜访客户数 = D_biz 去重客户数（家）
- 昨日拜访门店数 = D_biz 去重门店数（家）
- 参与拜访人数 = D_biz 去重人员数（人）
- 客户月累计覆盖率 = 本月截至昨天去重拜访客户数 ÷ 应拜访客户分母
- 门店月累计覆盖率 = 本月截至昨天去重拜访门店数 ÷ 应拜访门店分母
- 分母若表内无「应拜访」清单：先用探到的合理分母，并在回复末尾用一行注明分母来源；无法计算则覆盖率写「暂无法计算」且不编造
- 有效拜访：有拜访记录即算（签到/动作明细以实际表为准，不要另加停留时长过滤，除非字段明确）
- 负责人拜访：有负责人标识则按销售组/分区汇总「负责人昨日拜访经销数/门店数」；无标识则省略该半句
- 附个人明细：姓名 | 拜访经销数 | 拜访门店数（昨日）

【输出】
省区：【填写全名】
按《省区销售管理日简报 · 智能体训练说明》算①②③④⑤⑥
只回复六段结论正文（含④客户清单、⑥人员明细）；不要 PDF。
```
