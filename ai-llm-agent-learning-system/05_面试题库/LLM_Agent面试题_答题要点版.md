# LLM Agent 面试题库：答题要点版

## 1. Transformer 为什么适合语言建模？

- Self-Attention 建模 token 间依赖；
- 并行训练，比 RNN 扩展性强；
- 多头注意力学习不同语义关系；
- 适合 next token prediction；
- 局限是长序列成本高。

## 2. SFT、RLHF、DPO 区别？

- SFT：用指令-回答数据监督学习；
- RLHF：训练 reward model，再强化学习优化偏好；
- DPO：直接用偏好对优化，不显式训练 reward model；
- Agent 中可用于工具格式、指令遵循、安全对齐。

## 3. 大模型为什么会幻觉？

- 目标是预测 token，不是查事实；
- 缺少实时知识；
- 上下文不足；
- prompt 诱导强答；
- 多步推理错误累积；
- 缓解：RAG、工具、引用、验证、拒答。

## 4. 什么是 RAG？

- Retrieval-Augmented Generation；
- 先检索外部知识，再生成答案；
- 解决私有知识、实时知识、引用证据问题；
- 完整链路：解析、切分、索引、召回、重排、生成、评估。

## 5. RAG 失败原因？

- 解析失败；
- 切分不合理；
- embedding 不适合；
- top-k/rerank 失败；
- 上下文噪声；
- 模型忽略证据；
- 无测试集。

## 6. 长上下文能替代 RAG 吗？

- 不能完全替代；
- 长上下文成本高、噪声大、权限难控；
- RAG 支持选择、引用、更新、权限过滤；
- 二者互补。

## 7. Agent 和 Chatbot 区别？

- Chatbot 主要生成文本；
- Agent 有目标、状态、工具、环境反馈、多步循环；
- Agent 能执行任务，不只是回答。

## 8. ReAct 核心思想？

- Reasoning + Acting；
- Thought -> Action -> Observation 循环；
- 工具反馈修正推理；
- 工程要加最大步数、工具白名单、参数校验、trace。

## 9. Agent 主循环？

- 接收目标；
- 构造状态；
- 模型决策；
- 调用工具；
- 更新 observation；
- 检查终止；
- 输出结果。

## 10. 工具调用注意点？

- schema；
- 参数校验；
- 权限；
- 超时；
- 重试；
- 幂等；
- 审计；
- 高风险人工确认；
- 外部内容当数据不当指令。

## 11. 长上下文 vs 长期记忆？

- 长上下文：一次推理放更多 token；
- 长期记忆：跨会话持久化信息；
- 记忆需要写入、检索、更新、删除、权限；
- 长上下文不能处理长期偏好和事实变化。

## 12. 记忆系统怎么设计？

- 抽取；
- 存储；
- 检索；
- 更新；
- 删除；
- schema：content/type/source/time/confidence；
- 指标：召回、冲突更新、错误记忆、成本。

## 13. 如何避免记忆污染？

- 高置信写入；
- 用户确认重要记忆；
- 记录来源；
- 冲突检测；
- 支持删除；
- 过期机制；
- 外部文档不直接写长期记忆。

## 14. ReAct vs Plan-and-Execute？

- ReAct：边想边做，灵活；
- Plan-and-Execute：先规划再执行，全局清晰；
- 常组合：先 plan，每步 ReAct，失败 replan。

## 15. 反思机制作用和风险？

- 作用：失败经验写入上下文/记忆；
- 不更新参数也能改善后续任务；
- 风险：反思错误、上下文污染、反馈弱、强化坏策略。

## 16. 多 Agent 什么时候有价值？

- 角色分工；
- 并行探索；
- reviewer/critic；
- 多专家视角；
- 复杂任务协作；
- 风险：成本、延迟、争论、错误传播。

## 17. 多 Agent 协作协议？

- 角色职责；
- 消息格式；
- 工具权限；
- 冲突解决；
- 最大轮次；
- 终止条件；
- trace；
- 评估指标。

## 18. Agent 如何评估？

- 结果：成功率、正确率、满意度；
- 过程：步数、工具调用、成本、延迟；
- 安全：越权、注入、隐私；
- 方法：固定测试集 + trace + 人工抽检。

## 19. 如何防 prompt injection？

- 区分 instruction/data；
- 外部内容只当数据；
- 工具最小权限；
- schema 校验；
- 高风险确认；
- 敏感信息脱敏；
- 审计日志。

## 20. 生产级 Agent 架构？

- 接入层；
- 意图/风险识别；
- 规划；
- RAG/记忆；
- 工具层；
- 状态机执行；
- 评估；
- 安全；
- 日志和成本治理。

## 21. 企业知识库问答 Agent 设计？

- 文档接入；
- 清洗切分；
- 向量 + BM25；
- rerank；
- 带引用生成；
- 权限过滤；
- 拒答；
- 评估；
- 防注入。

## 22. 个人长期记忆助手设计？

- 记忆抽取；
- 分类存储；
- 检索注入；
- 冲突更新；
- 用户确认；
- 删除导出；
- 指标：偏好遵循、错误记忆、更新正确率。

## 23. 软件工程 Agent 设计？

- 读 issue；
- 搜索代码；
- 读文件；
- 生成计划；
- 应用补丁；
- 跑测试；
- 修复失败；
- 输出报告；
- 风险：误改、测试不足、危险命令。

## 24. Agent 评估平台设计？

- 测试集；
- 运行器；
- tool mock；
- trace；
- 指标；
- 失败分类；
- 报告；
- 回归对比。

## 25. Agent 项目怎么讲？

- 背景；
- 目标；
- 架构；
- 难点；
- 指标；
- 失败案例；
- 优化；
- 业务价值。

## 26. CodeAct 为什么重要？

- 代码作为行动空间；
- 支持变量、循环、条件、多工具组合；
- 解释器提供确定性反馈；
- 适合软件/数据任务；
- 必须沙箱、权限、超时。

## 27. MCP 解决什么问题？

- 标准化模型连接工具/资源；
- 方便扩展工具生态；
- 不解决规划、评估、安全全部问题；
- 生产仍需权限、审计、参数校验。

## 28. Agent 无限循环怎么办？

- 最大步数；
- 最大工具次数；
- 成本预算；
- 状态机；
- 明确 finish 条件；
- 重复动作检测；
- 失败降级。

## 29. Agent 成本如何优化？

- 上下文压缩；
- 小模型路由；
- 缓存；
- 减少无效工具；
- 并行控制；
- 检索 top-k 优化；
- early stop；
- trace 分析高成本路径。

## 30. 什么是 Agentic Reasoning？

- LLM 从静态回答转向计划、行动、反馈、协作；
- 包括规划、工具、搜索、记忆、反思、多 Agent；
- 可通过上下文编排或后训练优化；
- 目标是在动态环境中完成任务。
