## 6. 推荐关注的中文主题

### Agent 基础

搜索：

- `ReAct 智能体`
- `Plan and Execute Agent`
- `AI Agent 框架`
- `从零实现 Agent`
- `LangGraph 智能体`

要掌握：

- Agent loop；
- tool schema；
- action/observation；
- state graph；
- stop condition。

### 上下文工程

搜索：

- `上下文工程 AI Agent`
- `Context Engineering 智能体`
- `Manus 上下文工程`
- `长上下文 记忆 Agent`

要掌握：

- 不是把所有内容塞进 prompt；
- 要对上下文做选择、压缩、分层、清洗；
- 工具结果和历史消息都需要治理。

### MCP 与工具生态

搜索：

- `MCP 大模型`
- `Model Context Protocol 中文`
- `MCP 工具调用`
- `Claude MCP`
- `Agent 工具协议`

要掌握：

- MCP 是工具/资源接入协议；
- 生产系统仍然要做权限、审计、超时、参数校验；
- MCP 不替代 Agent 的规划和评估。

### 多智能体

搜索：

- `多智能体 协作 大模型`
- `AutoGen 多智能体`
- `CrewAI 中文`
- `MoA 多模型协作`

要掌握：

- 多智能体主要解决角色分工和并行探索；
- 风险是成本、冗余、争论、错误传播；
- 要设计通信协议和终止条件。

## 8. 每周固定阅读组合

建议每周组合如下：

1. 一篇国内资讯：了解趋势；
2. 一篇工程博客：了解落地；
3. 一篇论文摘要：了解研究；
4. 一个开源仓库 README：了解实现；
5. 一个自己的小实验：验证理解。

## 9. 如何判断一篇博客是否可靠

可靠信号：

- 有论文或官方文档链接；
- 有代码；
- 有实验指标；
- 有失败案例；
- 能说明适用边界；
- 不是只展示 demo 效果。

不可靠信号：

- 只说“颠覆”“炸裂”“最强”；
- 没有来源；
- 没有指标；
- 把 prompt 模板包装成通用框架；
- 不讨论成本和失败。
