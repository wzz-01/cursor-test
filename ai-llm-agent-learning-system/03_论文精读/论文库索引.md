## 每篇论文的最快阅读方法

1. 先读中文精读中的“解决什么问题”和“核心方法”；
2. 再读英文原文的 Abstract、Introduction、Method 图；
3. 看实验表格，只问三个问题：
   - baseline 是谁？
   - 指标是什么？
   - 提升是否来自方法本身？
4. 最后读局限和未来工作；
5. 写出面试表达：

```text
这篇论文解决的是 ______。
它的核心方法是 ______。
相比之前方法，它的关键差异是 ______。
实验说明它在 ______ 上有效。
如果工程落地，我会重点注意 ______。
```

| P0 | ReAct | Agent 基础循环，最值得手写复现 |
| P0 | CodeAct | 软件/工具 Agent 的关键范式 |

| P1 | AutoGen | 多智能体系统设计基础 |
| P1 | SWE-agent | 软件工程 Agent 面试价值高 |
| P2 | Toolformer | 更偏训练方法，工程复现成本较高 |
| P2 | LATS | 搜索式规划值得理解，完整复现较复杂 |
| P2 | Voyager | 思想重要，但 Minecraft 环境复现成本高 |
| P2 | Generative Agents | 记忆/社会模拟思想重要，工程成本中等 |

## 一周读一篇论文模板

每天 1 小时：

- 周一：中文精读 + Abstract + Introduction；
- 周二：Method；
- 周三：Experiments；
- 周四：Related Work + Limitations；
- 周五：写 1 页中文总结；
- 周六：做一个最小复现实验或伪代码；
- 周日：用 3 分钟口头讲给别人听。
