## 5. 论文到面试的转换方法

每读一篇论文，都要转成下面 5 种材料：

1. **一句话版**：这篇论文解决什么问题；
2. **三分钟版**：问题、方法、实验、局限；
3. **面试题版**：面试官会怎么问；
4. **项目版**：能不能用到自己的项目；
5. **风险版**：生产落地会失败在哪里。

示例：

```text
论文：ReAct
一句话：ReAct 通过 Thought/Action/Observation 循环，把模型推理和外部工具反馈结合。
面试题：ReAct 和 CoT 有什么区别？
项目版：实现工具调用 Agent 的基本控制循环。
风险版：容易死循环、工具误调、没有权限控制。
```

## 6. 面试回答评分标准

| 分数 | 标准 |
| --- | --- |
| 1 | 只会背名词 |
| 2 | 能解释概念，但没有工程细节 |
| 3 | 能讲机制和简单例子 |
| 4 | 能讲工程落地、风险和评估 |
| 5 | 能结合论文、项目、指标和取舍 |

## 7. 每月必须补齐的材料

1. 4 篇论文卡片；
2. 20 道面试题答案；
3. 1 个项目模块；
4. 1 份失败案例复盘；
5. 1 次模拟面试录音；
6. 1 份简历项目描述更新。
