# 学习路线总览

## 一、总体结构

本计划把大模型与 LLM Agent 能力拆成 10 个层级：

1. LLM 基础：Transformer、预训练、token、上下文、幻觉。
2. 后训练与对齐：SFT、RLHF、DPO、RLAIF、RLVR、推理模型。
3. Prompt 与上下文工程：结构化输出、上下文选择、压缩、隔离。
4. RAG：文档解析、切分、检索、重排、引用、评估。
5. Tool Use：函数调用、工具学习、代码行动、MCP、权限。
6. Agent 架构：ReAct、Plan-and-Execute、状态图、反思、搜索。
7. Memory：短期记忆、长期记忆、图记忆、冲突更新、遗忘。
8. Multi-Agent：角色协作、通信协议、投票、审查、成本控制。
9. Evaluation & Safety：benchmark、trace、成本、安全、prompt injection。
10. Software/Research Agent：代码修改、测试反馈、研究助手、端到端系统设计。

## 二、32 周学习阶段

| 阶段 | 周数 | 主题 | 产出 |
| --- | --- | --- | --- |
| A | 1-4 | LLM 基础、后训练、推理 | LLM 基础面试题 30 道 |
| B | 5-8 | Prompt、上下文工程、RAG | 带引用 RAG Demo |
| C | 9-12 | Tool Use、ReAct、规划与反思 | 工具调用 Agent |
| D | 13-16 | Memory、Agentic Memory、长期任务 | 长期记忆助手 |
| E | 17-20 | Multi-Agent、CodeAct、软件工程 Agent | 多 Agent + CodeAct Demo |
| F | 21-24 | Evaluation、Safety、Observability | Agent 测试集与 trace 报告 |
| G | 25-28 | Agentic RAG、Deep Research、行业落地 | 研究助手项目 |
| H | 29-32 | 综合系统设计、面试冲刺、作品集 | 简历项目与模拟面试 |

## 三、每周固定输出

每周必须产出：

1. 1 篇论文卡片；
2. 5 道面试题口头答案；
3. 1 个小实验或项目模块；
4. 1 个失败案例复盘；
5. 1 段可写进简历的项目描述草稿。

## 四、每月能力检查

每 4 周做一次检查：

| 检查项 | 合格标准 |
| --- | --- |
| 论文理解 | 能讲清 4 篇论文的问题、方法、指标、局限 |
| 面试表达 | 能连续回答 20 分钟大模型/Agent 问题 |
| 项目能力 | 有可运行代码或清晰系统设计 |
| 工程意识 | 能说明成本、延迟、安全、失败处理 |
| 复盘能力 | 能给出下一步优化方案 |

## 五、学习优先级

如果时间不够，优先级如下：

1. ReAct、RAG、Tool Use、Memory、Evaluation；
2. CodeAct、SWE-agent、Multi-Agent；
3. 后训练、推理模型、Agentic RAG；
4. 多模态、具身、社会模拟；
5. 产业报告和产品新闻。

## 六、面试表达总框架

回答任何大模型/Agent 问题，都尽量按这个结构：

1. 一句话定义；
2. 为什么需要它；
3. 核心机制；
4. 工程落地怎么做；
5. 常见失败和风险；
6. 如何评估；
7. 和论文/项目的关联。

示例：

```text
Agent 不是普通聊天机器人，而是围绕目标进行规划、工具调用、状态更新和多步执行的系统。
它需要 ReAct 或状态图来组织执行，需要 RAG 和 Memory 提供上下文，需要工具权限和 trace 保证安全和可观测。
评估时不能只看最终回答，还要看任务成功率、工具调用次数、成本、延迟和安全失败率。
```
