# 大模型与 LLM Agent 高级完整学习计划

> 这是一个全新的独立资料库，不放在上一版 `ai-llm-agent-learning-system/` 下。

## 和上一版的区别

上一版更像“入门到系统化”的资料库，重点是建立学习框架、下载核心论文、做基础面试准备。

本版是“高级完整课程 + 论文精读路线 + 面试训练体系”，重点升级为：

1. 论文数量从 14 篇扩展到 **60 篇**；
2. 每篇论文都有独立的学习定位、核心贡献、面试价值和学习方法；
3. 每节课都包含：
   - 学习目标；
   - 重点知识；
   - 当天 1 小时学习安排；
   - 大模型/Agent 面试题；
   - 面试题详细讲解；
   - 答题核心要点；
   - 课后产出；
4. 课程从 LLM 基础、后训练、RAG、Agent、记忆、多智能体、评估、安全、软件工程 Agent、系统设计一路打通；
5. 更强调“能读论文、能做项目、能面试表达、能判断技术价值”。

## 总体学习目标

完成本计划后，应达到以下能力：

1. **论文能力**：看到一篇 LLM/Agent 论文，能在 30 分钟内判断它解决什么问题、是否值得精读、能否用于项目。
2. **工程能力**：能设计 RAG、Agent、Memory、Tool Use、Multi-Agent、Evaluation 的完整系统。
3. **面试能力**：能回答大模型基础、RAG、Agent、后训练、评估、安全、系统设计和项目复盘问题。
4. **研究判断能力**：能区分真正的新范式、工程优化、benchmark 刷分和营销型文章。
5. **作品集能力**：能形成至少 4 个可展示项目，并说明指标、失败案例和改进路线。

## 课程节奏

默认每天 1 小时，每周 5 天学习，周末用于复盘或补课：

- 10 分钟：复习前一节课；
- 30 分钟：学习新内容或读论文；
- 15 分钟：回答本节面试题；
- 5 分钟：记录一句可复述结论。

## 推荐使用顺序

1. 先读 `00_总入口/学习路线总览.md`；
2. 按 `01_完整课程计划/32周完整课程_逐课含面试题.md` 每天执行；
3. 每周从 `02_论文库_60篇精读/60篇论文完整清单与学习顺序.md` 选择论文；
4. 用 `02_论文库_60篇精读/60篇论文逐篇要点分析.md` 快速建立理解；
5. 用 `03_逐课面试题/逐课面试题_详细讲解与答题要点.md` 做面试训练；
6. 每 4 周完成一个小项目或项目模块；
7. 每月做一次模拟面试和项目复盘。

## 重要原则

- 不要只收藏论文，要写自己的“问题-方法-指标-局限”总结。
- 不要只跑 demo，要记录 trace、失败案例和指标。
- 不要只背面试题，要能把论文、项目、工程风险连起来讲。
- 不要盲目追最新模型，要围绕 Agent 能力栈建立长期判断。
